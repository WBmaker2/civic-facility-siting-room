# 콘텐츠·안전 검토 기록

- 검토일: 2026-08-26
- 검토자: Codex 구현 세션(교사 확인 전)
- 검토 성격: AI-assisted 검토이며 교사 확인 전입니다. 사람의 공식 서명이나 승인으로 간주하지 않습니다.

## 1. 교육과정 출처 확인

- 출처 제목: **2022 개정 초중등학교 교육과정 고시 안내** (국가교육과정정보센터, NCIC)
- 직접 URL: https://ncic.go.kr/board/B0031.cs?act=read&bwrId=1271&pageIndex=1&pageUnit=15
- 확인일: 2026-08-26
- 확인한 내용: 위 NCIC 고시 안내에서 2022 개정 교육과정의 사회과 교육과정(별책 7) 원문 안내를 확인하고, 초등 사회 성취기준 `[4사10-02]`의 문구를 대조했습니다. 확인 문구는 **“사례에서 도시의 인구, 교통, 산업 등의 특징을 탐구하고, 도시에서의 삶의 모습을 이해한다.”**입니다.
- 결정: 도시의 인구·교통·산업과 삶을 사례로 탐구한다는 취지를 전제로, 가상 격자에서 거리·시간·사람 토큰·자료를 비교하는 확장 활동으로 사용합니다. 이 앱은 실제 도시계획을 제시하지 않습니다.
- 코드/배치 확인: 확인한 공식 원문과 설계 문서에서 `[4사10-02]`의 코드·문구 차이는 발견하지 못했습니다. 이후 공식 원문과 다른 판본이 확인되면 교사 확인 전에는 learner-copy 승인 상태를 유지하지 않고 차이를 기록·재검토합니다.

## 2. 학년 위치와 학습 의도

`[4사10-02]`를 도시 생활을 살펴보는 선행 학습으로 위치시키고, 본 앱은 5~6학년 확장 활동으로 설계했습니다. 학습자는 실제 장소를 입력하지 않고 가상 도시의 구역별 사람 토큰, 이동 단위, 위험 표지, 비용을 비교합니다. 핵심은 하나의 최적 경로를 찾는 것이 아니라, 여러 구역에 미치는 시설 입지 효과와 접근성 차이를 근거로 절충과 보완안을 설명하는 것입니다.

## 3. 승인된 학습자 용어

다음 용어를 UI와 미션에서 일관되게 사용합니다.

`가상 도시`, `구역`, `사람 토큰`, `이동 단위`, `예산 토큰`, `위험 표지`, `도달 불가`, `소외 구역`, `절충`, `보완안`

## 4. 차별화 확인

- 한 경로의 빠르기보다 여러 구역에 걸친 **다중 구역 시설 입지 효과**를 비교합니다.
- 주소·장소 기록이 아니라 가상 그래프의 **공간 접근성**을 비교합니다.
- 자원을 누구에게 배분할지의 원칙만 묻지 않고, **위치가 바뀌어 생기는 접근 차이**를 살핍니다.

## 5. 사회적 언어와 건강 안전성

문장은 주민이나 특정 구역을 탓하지 않습니다. 접근하기 어려운 결과는 주민 개인의 잘못이 아니라고 명시합니다. 건강 미션의 시설명은 정확히 **`일상 건강 상담 시설`**로 쓰며, 응급실·응급 대응·응급 서비스가 아님을 안내합니다. 따라서 이 모델은 응급 대응이나 응급 서비스 성능을 다루거나 예측하지 않습니다.

## 6. 개인정보와 모델 한계

실제 장소·주소·GPS·지역명·정책 입력을 받지 않고, 모든 도시는 명시적으로 허구입니다. 상대 이동 단위와 토큰은 학습용 값이며 실제 교통량·토지 소유·법률·재난을 반영하지 않습니다. 결과는 실제 도시계획을 대신하거나 정책 판단·예측으로 해석할 수 없습니다. 입력은 현재 탭에만 남고 새로고침하면 사라진다는 안내를 제공합니다.

## 승인 결정

콘텐츠와 안전 문구를 위 결정대로 승인하여 도메인 fixture 구현을 진행했습니다. 공식 출처 대조 및 이 결정은 **AI-assisted, 교사 확인 전**이며, 교사가 `[4사10-02]`의 학년·문구·확장 범위를 확인한 뒤 최종 교육과정 승인을 완료해야 합니다.
